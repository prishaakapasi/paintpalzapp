# PaintPalz 

A therapeutic creative app designed to support pediatric hospital patients through art and connection.

**Role:** Product Designer, UI/UX Designer, Mobile Developer
**Timeline:** Jun 2024 – Jun 2025
**Tech Stack:** React Native, Expo, JavaScript, Supabase, Figma, Adobe Illustrator

[Portfolio case study →](https://www.prishaakapasi.com/engineering)

<br>

## overview

PaintPalz is a mobile app designed as a therapeutic outlet for pediatric hospital patients. Inspired by observing how technology can transform hospital environments, I built PaintPalz to help young patients feel less isolated and more emotionally supported during their stay. The app fosters creativity, self-expression, and connection through interactive art-based experiences and a shared community space.

<br>

## features

-  Avatar creation system with 100+ inclusive, customizable avatars tied to user identity and experience
-  Paint-by-numbers with structured, therapeutic activities, prompts, and color randomization
-  Free drawing canvas with adjustable brushes, colors, and a 300+ prompt generator
-  Personal gallery to save and reflect on artwork, with the option to share to a community gallery
-  Gamified reward system where users earn coins to customize avatars, encouraging continued engagement

<br>

## tech stack

`React Native` &nbsp;`Expo` &nbsp;`JavaScript` &nbsp;`Supabase` &nbsp;`Figma` &nbsp;`Adobe Illustrator`

Developed with React Native and Expo for cross-platform compatibility across iOS and Android. Supabase handles data storage and user-generated content, including artwork and profiles. The interface was designed in Figma through iterative wireframing and prototyping, and custom graphics, including 100+ avatars and UI elements, were created in Adobe Illustrator. Built with modular, scalable components to support future expansion into real-world hospital settings.

## getting started

```bash
# clone the repo
git clone https://github.com/prishaakapasi/paintpalzapp.git
cd paintpalzapp

# install dependencies
npm install

# start the app
npx expo start
```

Scan the QR code with the Expo Go app, or run on a simulator with `i` (iOS) / `a` (Android).

## challenges

Balancing simplicity with meaningful functionality for a young and potentially stressed user base was central to the design. Smooth, responsive drawing interactions across devices, especially iPads, required careful optimization. Every design choice, from palette to navigation, aimed to feel calming, intuitive, and inclusive.

<br>

## outcome

- Designed and developed a fully functional, cross-platform therapeutic art application
- Created 100+ custom-designed avatars and a cohesive visual system
- Explored the intersection of technology, creativity, and healthcare through human-centered design
